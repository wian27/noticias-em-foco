O GitHub Pages publica arquivos estáticos e não registra visitas por conta própria. Este painel consulta a API oficial do GA4 depois que você conectar uma propriedade. A chave de acesso não fica gravada nesta página.

1 · Ative o GA4Crie uma propriedade e um fluxo Web para o endereço wian27.github.io/noticias-em-foco.
2 · Configure o acessoNo Google Cloud, habilite Google Analytics Data API e crie um OAuth Client ID do tipo aplicativo Web.
3 · Informe os IDsAdicione a origem https://wian27.github.io aos domínios autorizados do OAuth e preencha os três campos abaixo.

Usado para instalar a medição das visitas no portal. Depois de criar o GA4, me envie esse ID para ativar no site.

Número da propriedade GA4, sem o prefixo “properties/”.
